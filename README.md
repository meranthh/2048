## Что умеет игра

- поле 4x4 создаётся с помощью JavaScript
- в начале игры на поле 1-3 плитки со значением 2 или 4
- после каждого хода появляются 1-2 новые плитки в случайных свободных клетках
- плитки двигаются и сливаются во все 4 стороны
- подсчёт очков (складываются значения объединённых плиток)
- отмена последнего хода (после окончания игры отменить нельзя)
- кнопка «Начать заново» без перезагрузки страницы
- проверка окончания игры, когда больше нельзя сделать ход
- после окончания игры можно ввести имя и сохранить рекорд
- таблица лидеров (топ-10): имя, очки, дата
- состояние игры и таблица лидеров хранятся в localStorage
- у каждого значения плитки свой цвет
- анимация движения и слияния плиток
- адаптивная вёрстка для компьютера, планшета и телефона

## Управление

- на компьютере — стрелки на клавиатуре
- на телефоне и планшете — кнопки под полем

## Технологии

HTML, CSS, JavaScript (без фреймворков)
